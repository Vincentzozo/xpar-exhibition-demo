# XPAR PC 软件 · 展会版

采用 XPAR 黑色与薄荷绿配色的PC界面原型，保留实时监测、光谱分析、历史与DLI、记录与导出四页，支持中英切换，无需登录。

在线预览：https://vincentzozo.github.io/xpar-exhibition-demo/

默认显示两台 X400 示例设备、读数、光谱和静态示例历史。数据标注为“示例数据 · 非实测”；点击顶部“示例数据”可切换到空设备视图。无光照滑杆或场景预设。示例导出标注 EXAMPLE，支持CSV、Excel和曲线PNG。

实际串口/Modbus通信尚未接入，示例模式不会下发设备指令。下载 index.html 可离线查看。
